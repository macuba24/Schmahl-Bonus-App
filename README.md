# Kundenkarte Schmahl

Eine Seite für das Handy. Name, Kundenkode, Buchung, Foto und Nachricht bleiben auf diesem Gerät.

## Auf Render

Static Site, Branch `main`. Build Command leer lassen. Publish Directory ist `.`

## Am Handy

Die Render-Adresse in Chrome öffnen und zum Startbildschirm hinzufügen. Kunde und Kasse liegen auf demselben Handy. Der Prospekt hängt unter `prospekt.html`.
